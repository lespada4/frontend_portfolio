# Инструкция по запуску проекта

## Как запустить локально

Выполните следующие команды в терминале:

```bash
# 1. Склонировать репозиторий
git clone https://github.com/lespada4/frontend_portfolio.git

# 2. Перейти в папку проекта
cd frontend_portfolio

# 3. Установить зависимости
npm install

# 4. Запустить в режиме разработки
npm run dev
```

После этого откройте в браузере http://localhost:3000 - страница бронирования должна загрузиться.

## Запуск тестов

Для проверки работоспособности выполните:

```bash
npm test
```

Тесты должны показать зелёный результат

# О чём думал, когда делал

## Структура

Разбил на три части:
* **BookingForm** - сама форма.
* **ConfirmationScreen** - экран после отправки.
* **index** - просто переключатель между ними.

Потому что каждая часть решает свою задачу. Если их смешать, получится каша.

---

## Валидация

Сделал так, чтобы ошибки показывались сразу, когда ты переходишь к следующему полю (`onBlur`), а не только в момент отправки. Сам не люблю, когда форма кричит на тебя только после нажатия кнопки.

Телефон принимает любые пробелы, скобки и дефисы, а в коде я чищу всё, кроме цифр. Главное, чтобы в итоге было 11 цифр и начиналось с 7 или 9
---

## Отправка

`setTimeout` на полторы секунды и лоадер на кнопке. Это имитация бекэнда. Я думал попробовать задеплоить на свой арендованный VPS, но в задании написано, что в этом нет необходимости
---

## Адаптивность

Сделал базовые медиа-запросы. На мобильном (**375px**) выглядит нормально, на десктопе - тоже. В целом кнопки не деформируются, надписи читаемы

---

## Тесты

Написал только один интеграционный тест и проверку функции для телефона. Решил, что этого достаточно, чтобы показать, что я понимаю, как тестировать React-компоненты. Тесты работают, проходят зелёными — и это уже плюс.
